# SpaceX Falcon 9 Landing Prediction

This project analyzes SpaceX Falcon 9 launch data to predict whether the first stage will land successfully.

## Contents
- Data collection and wrangling notebooks
- Exploratory data analysis (EDA)
- SQL analysis
- Machine learning models
- Plotly Dash interactive dashboard

## Dashboard
Run:
python3.11 spacex-dash-app.py
